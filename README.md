# TStamp

A lightweight, local-first terminal timestamp utility.

Status: early development (Phase 2, project skeleton).

Planned layout:

- `bin/`    the `tstamp` command
- `lib/`    shared core (config, formats, logging, export)
- `shells/` shell integrations (Git Bash first)
- `docs/`   offline manual source
- `tests/`  test scripts

No cloud accounts, telemetry, AI APIs or background service are required.
