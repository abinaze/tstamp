# Contributing

You do not need to write code to help.

- **Report a problem.** Open an issue and choose "Bug report". Say what you typed,
  what you expected, and what happened.
- **Improve the words.** If something on these pages confused you, tell us or fix it.
  Documentation fixes are welcome.
- **Test on your computer.** Systems marked "not tested" on the
  [compatibility](compatibility.md) page need someone to try them.
- **Suggest an idea.** Open an issue and choose "Feature request".

To change the code, read the developer guide in
[CONTRIBUTING.md](../CONTRIBUTING.md). In short: run `bash tests/run_all.sh`
before and after your change, and add a test for what you changed.

Security problems should not be posted publicly. See [SECURITY.md](../SECURITY.md).
Please be kind: [Code of Conduct](../CODE_OF_CONDUCT.md).
