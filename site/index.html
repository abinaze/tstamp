Know when every command ran, and how it ended.

tstamp adds a start time, an end time, the result and the duration to every command in your terminal, across all your windows. Free, open source, and nothing ever leaves your computer.

Install tstamp Quick start

curl -fsSL https://github.com/abinaze/tstamp/releases/latest/download/get.sh | bash

MIT license · bash on Windows, Linux and macOS

Install

Each system has its own package. Choose yours, follow the steps, done.

  1. Get Git for Windows

    tstamp runs in Git Bash, which comes with it. Skip this if you already have it.

    git-scm.com/download/win

  2. Download and open the installer

    No administrator rights needed. If Windows says “unknown publisher” (the installer is not code-signed), choose More info, then Run anyway. Keep “Load tstamp in every new Git Bash window” ticked; your ~/.bashrc is backed up first.

    Download tstamp-windows-setup.exe

  3. Turn it on

    Open a new Git Bash window and run:

    tstamp-a

Uninstall: Windows Settings, then Apps, then tstamp.

  1. Download the package

    Download tstamp.deb

  2. Install it

    sudo apt install ./tstamp.deb

  3. Load it in new terminals

    Asks before changing anything, and saves a backup.

    tstamp hook add

  4. Turn it on

    In a new terminal:

    tstamp-a

Uninstall: tstamp hook remove, then sudo apt remove tstamp.

  1. Install

    No sudo. It downloads the package, checks it is not damaged, and installs for your user only.

    curl -fsSL https://github.com/abinaze/tstamp/releases/latest/download/get.sh | bash

    On a Mac: Terminal uses zsh and an old bash, and tstamp supports neither. First run brew install bash, then type bash.

  2. Load it in new terminals

    Asks before changing anything, and saves a backup.

    tstamp hook add

  3. Turn it on

    In a new terminal:

    tstamp-a

Prefer to look first? Download tstamp-unix.tar.gz, unpack it and run bash install.sh. Uninstall: bash ~/.local/share/tstamp/uninstall.sh

Check your download

Each release has SHA256SUMS.txt. Compare your file with its line. A match means the file is not damaged. It cannot protect you if a release itself were replaced.

Questions

Does it send my commands anywhere?

No. tstamp makes no network connections and has no telemetry. It saves a log in ~/.tstamp/logs. That log has the full text of every tracked command, including any password typed inside one, so run tstamp stop first and delete old logs.

Will it change my commands or their output?

No. Your command, its output and its result are left alone. tstamp only adds the START and END lines.

Why does Windows need Git Bash?

tstamp is a bash tool, and Git for Windows provides bash. The installer checks and tells you if it is missing.

Is it safe to run the Windows installer?

It is not code-signed, because certificates cost money, so Windows warns about any unsigned download. The source is open, and you can compare your download with SHA256SUMS.txt.

How do I report a security problem?

Privately. See SECURITY.md.
