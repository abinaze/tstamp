Know exactly when every command ran.

TStamp prints a start and an end timestamp, the exit code and the duration around every command in your terminal. No account, no telemetry, no background service.

See install options View on GitHub

MIT license · works in bash on Windows, Linux and macOS

Install

Each system has its own package. You only need yours.

Windows

TStamp runs inside Git Bash. Install Git for Windows first if you do not have it.

Download tstamp-windows-setup.exe

  1. Run the downloaded file. No administrator rights are needed.
  2. Windows SmartScreen may warn because the installer is not code-signed. Choose More info, then Run anyway.
  3. Leave “Load TStamp in every new Git Bash window” ticked. The installer backs up ~/.bashrc first.
  4. Open a new Git Bash window and type tstamp-a.

Uninstall from Windows Settings, then Apps. It removes exactly what it added.

Debian and Ubuntu

Download tstamp.deb

sudo apt install ./tstamp.deb

Then run tstamp hook add once, open a new bash window and type tstamp-a.

Uninstall: tstamp hook remove, then sudo apt remove tstamp.

Linux, macOS and WSL

One command, no sudo. It downloads the package, checks its checksum and installs for your user.

curl -fsSL https://github.com/abinaze/tstamp/releases/latest/download/get.sh | bash

It edits no startup file unless you add -s -- --hook after bash. Prefer to inspect first? Download tstamp-unix.tar.gz, unpack it and run bash install.sh.

On a Mac: Terminal opens zsh and ships bash 3.2, and TStamp supports neither. Run brew install bash, start it by typing bash, then install.

Uninstall: bash ~/.local/share/tstamp/uninstall.sh

Verify your download

Every release has a SHA256SUMS.txt. Compare the checksum of your file with the matching line.

Get-FileHash .\tstamp-windows-setup.exe -Algorithm SHA256   # Windows PowerShell
sha256sum tstamp-unix.tar.gz                                # Linux, Git Bash
shasum -a 256 tstamp-unix.tar.gz                            # macOS

A checksum from the same page catches a damaged download. It cannot protect you if the release itself were replaced.

What it does

Start and end, every time

A START line before each command and an END line when it finishes, with the exit code and the duration. Your command’s own output, pipelines and exit status are left alone.

One switch for every terminal

tstamp-a turns tracking on in every terminal that has loaded the hook, windows that are already open included. tstamp stop turns it off. No restarts.

Sessions you can tell apart

Each terminal gets its own ID (T1, T2, …) and its own log, so an error in one window never blurs into another.

Your own format

Five built-in formats, or any date format string, including milliseconds with %3N on every system.

One merged timeline

tstamp export combines the logs of the sessions you pick into a single report in time order.

Local and safe

No network access, no accounts, no telemetry and no background service. Installers ask before touching your startup file, back it up first and remove only what they added.

Commands

CommandWhat it does
tstamp [FORMAT]Track this terminal, optionally with a format.
tstamp-a [FORMAT]Track every terminal with the hook. Switches itself off after a reboot.
tstamp stopStop tracking globally and in this terminal.
tstamp statusShow global and per-terminal status.
tstamp formatList the timestamp formats.
tstamp set FORMATChange the saved default format.
tstamp export [-o FILE] [T1 T2]Merge session logs into one chronological report.
tstamp hook add|removeAdd or remove the startup-file block, with a backup.
tstamp help, man, examples, versionOffline help and the full manual.
tstamp resetRestore the default configuration.

Privacy and security

  • TStamp makes no network connections, sends no telemetry and needs no account.
  • Logs live in ~/.tstamp/logs, unencrypted and readable by your user account. They contain the full text of every tracked command, including any secret typed on a command line. Run tstamp stop before typing secrets and delete old logs.
  • This website loads no third-party scripts, fonts or trackers. Its only network request is an optional lookup of the latest release at api.github.com.
  • Found a vulnerability? Please report it privately, as described in SECURITY.md.

Questions

Does it work in zsh, fish, PowerShell or CMD?

Not yet. TStamp supports bash today. macOS Terminal opens zsh by default, so on a Mac start bash first.

Why does the Windows version need Git Bash?

TStamp is a bash tool, and Git for Windows provides bash. The installer checks for it and tells you if it is missing.

Windows warns about the installer. Is it safe?

The installer is not code-signed, because certificates cost money, so SmartScreen warns about any unsigned download. The source is open, and you can compare your download with SHA256SUMS.txt.

Will it still be on after a reboot?

Global tracking switches itself off after a reboot. Run tstamp-a again. A real restart has not been tested yet; the check has only been verified with simulated boot markers.

Where are my logs?

In ~/.tstamp/logs, one file per terminal. tstamp export merges them into one report.

How do I uninstall it?

On Windows, use Settings, then Apps. On Debian and Ubuntu, run sudo apt remove tstamp. Elsewhere, run bash ~/.local/share/tstamp/uninstall.sh. Each one removes what it added and asks before deleting your logs.
