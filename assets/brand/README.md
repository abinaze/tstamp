# tstamp brand assets

The symbol is a block cursor beside a ruler scale: a terminal cursor, and a
way of measuring time.

| File | Use |
|---|---|
| `svg/tstamp-horizontal-dark.svg` | Symbol and name for light backgrounds, such as the website header |
| `svg/tstamp-horizontal-light.svg` | The same for dark backgrounds |
| `svg/tstamp-symbol-dark.svg`, `svg/tstamp-symbol-light.svg` | Symbol alone, no background |
| `svg/tstamp-icon.svg` | Symbol on a dark rounded square: favicon, GitHub avatar, package icon |
| `svg/tstamp-wordmark-dark.svg`, `svg/tstamp-wordmark-light.svg` | Name alone |
| `png/` | The same as PNG: horizontal 1000 px wide, symbol 512 px, icon 512, 180 and 32 px |

The SVG files contain no fonts: the name is converted to outlines, so it looks
the same everywhere.

## Colours

| Name | Hex | Use |
|---|---|---|
| Ink | `#14181D` | Dark logo, dark icon tile |
| Paper | `#F4F6F8` | Light logo |

Use the dark logo on light backgrounds and the light logo on dark ones. Do not
recolour, stretch or add shadows or effects. Keep clear space around the logo
equal to the width of the cursor block.

## Typeface

The name is set in DejaVu Sans Mono Bold (free licence).
