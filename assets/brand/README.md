# tstamp brand assets

The symbol is a time colon made of two block cursors, set inside the square
brackets that wrap the session ID and timestamp in tstamp's own output.

| File | Use |
|---|---|
| `svg/tstamp-horizontal-dark.svg` | Symbol and wordmark for light backgrounds, such as the website header |
| `svg/tstamp-horizontal-light.svg` | The same for dark backgrounds |
| `svg/tstamp-symbol-dark.svg`, `svg/tstamp-symbol-light.svg` | Symbol alone, no background |
| `svg/tstamp-icon.svg` | Symbol on a dark rounded square: favicon, GitHub avatar, package icon |
| `svg/tstamp-wordmark-dark.svg`, `svg/tstamp-wordmark-light.svg` | Name alone |
| `png/` | The same as PNG: horizontal 1000 px wide, symbol 512 px, icon 512, 180 and 32 px |

SVG files contain no fonts: the wordmark is converted to outlines, so it looks
the same everywhere.

## Colours

| Name | Hex | Use |
|---|---|---|
| Ink | `#14181D` | Dark logo, dark icon tile |
| Paper | `#F4F6F8` | Light logo |

Use the dark logo on light backgrounds and the light logo on dark ones. Do not
recolour, stretch, add shadows or effects. Keep clear space around the logo
equal to the width of one bracket.

## Typeface

The wordmark is set in DejaVu Sans Mono Bold (free licence, outlines embedded
in the SVG files).
